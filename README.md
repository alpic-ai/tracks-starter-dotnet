# .NET starter

A minimal ASP.NET Core web app in C# with one minimal API endpoint and no database.

- `Program.cs`: the app and its `GET /` endpoint
- `app.csproj`: the project file
- `appsettings.json`: its configuration
- `Properties/launchSettings.json`: the local URLs `dotnet run` listens on

## Run

```sh
dotnet run
```

Then open http://localhost:5267.
